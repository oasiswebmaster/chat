1. Original Scope & Agreement

The contract amount of $2,800.00 was defined for the design and deployment of the following core parameters:

  • Website Facelift: Responsive layout replacing the old WordPress site.
  • Sites Sales and Rentals: Grid database cards displaying Buying/Renting lot listings.
  • Media Area: Resource index for downloadable documents and forms.
  • Social Events Calendar: Interactive calendar display for co-owners.
  • Classified Ads: Board for listings co-owners want to sell.
  • Basic Community Portal: Core resident layout for documents and announcements.
